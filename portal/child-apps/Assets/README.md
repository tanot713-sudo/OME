# Equipment/Assets app — portal retrofit

ต้นฉบับ **ไม่มีการเช็คสิทธิ์เลย** — `doGet()` เปิดให้ทุกคน และ `updateRow`/
`addRow`/`deleteRow` (แม้จะไม่ถูกเรียกจากหน้าเว็บปัจจุบันเลยก็ตาม) ยังเรียกตรงผ่าน
`google.script.run` จาก console ได้อยู่ดี เพราะ Apps Script เปิดให้เรียกทุกฟังก์ชัน
top-level โดยอัตโนมัติ

## สิ่งที่แก้

- `doGet(e)` เรียก `portalGuard(e, 'sec-assets-dash')` ก่อนสร้างหน้าเว็บ ฝัง
  `window.PORTAL.token` เข้าไปด้วย `.append()` (ไฟล์ยังใช้
  `createHtmlOutputFromFile` เหมือนเดิม ไม่ต้องแปลงเป็น template)
- `getAssetData(portalToken)` ยืนยันสิทธิ์กับ Hub ก่อน แล้วกรองแถวด้วย
  `scopeRows(rows, access, 'plant (โครงการ)')` — ใช้คอลัมน์ `plant (โครงการ)`
  เป็นตัวผูกกับรหัสโครงการของ Hub
- `updateRow`/`addRow`/`deleteRow` เพิ่ม `portalToken` เป็นพารามิเตอร์แรก + เช็ค
  สิทธิ์ก่อนทำงานทุกครั้ง (แม้จะยังไม่ถูกเรียกจริงจากหน้าเว็บ): แก้ไข (`updateRow`)
  ต้องเป็นโครงการที่ผู้ใช้เห็นได้ (`canSeeProject`) และมีสิทธิ์เขียน (`canWrite`);
  เพิ่ม/ลบสินทรัพย์ (`addRow`/`deleteRow`) จำกัดเฉพาะ admin/manager (`isAdminish`)
  เพราะเป็นการเปลี่ยนโครงสร้างระดับองค์กร ไม่ใช่แก้ข้อมูลในโครงการตัวเอง
- `sendWarrantyAlert()` ไม่ได้แก้ (สมมติว่าทำงานผ่าน time-based trigger เท่านั้น
  ไม่ได้ถูกเรียกจากหน้าเว็บ) — ถ้าจริงๆ มีปุ่มเรียกฟังก์ชันนี้ตรงๆ ต้องเพิ่มการเช็ค
  สิทธิ์แบบเดียวกับฟังก์ชันเขียนข้อมูลด้านบน

## สิ่งที่ต้องยืนยันก่อน deploy จริง

**คอลัมน์ `plant (โครงการ)`** ที่ใช้ผูกกับ `Sheet_Projects.code` — สมมติว่าค่าใน
คอลัมน์นี้ตรงกับรหัสโครงการเดียวกับที่ Project List/Finance ใช้ (เช่น `NB230004`)
**ยังไม่ได้ตรวจกับข้อมูลจริง** ถ้ารหัสไม่ตรงกัน (เช่นเป็นชื่อโครงการเต็มแทนที่จะเป็น
รหัส) ทุกคนที่ไม่ใช่ admin/manager จะเห็นข้อมูลว่างเปล่าตอนเปิดใช้งานจริง — แนะนำให้
เพิ่มคอลัมน์ `aliases` ใน `Sheet_Projects` (ดูแผน Phase 0) แทนการเปลี่ยนข้อมูลในชีตนี้

## ทดสอบแล้ว

- Shadow mode (`PORTAL_ENFORCE=false`): ผู้ใช้ที่ยังไม่มีสิทธิ์เมนูนี้เลยเห็นข้อมูล
  ครบเหมือนวันนี้ทุกอย่าง (ไม่ถูกบล็อก ไม่ถูกกรอง) — ส่วนผู้ใช้ที่ Hub กำหนดสิทธิ์
  เมนู+โครงการไว้แล้วจริง จะเห็นข้อมูลกรองตาม scope ทันที (ถูกต้องแล้ว เพราะถ้าถึงจุด
  นี้ได้แปลว่า Phase 0 เตรียมข้อมูลเสร็จแล้ว)
- Enforce mode: engineer ที่ผูกกับโครงการ A เห็นเฉพาะแถวโครงการ A, แก้ไขแถว
  โครงการ B ไม่ได้, เพิ่ม/ลบแถวไม่ได้ (ไม่ใช่ admin/manager); admin เห็น/แก้/เพิ่ม/
  ลบได้ทุกแถว

## วิธี deploy

1. เปิด Apps Script project ของแอป Equipment/Assets เดิม
2. แทนที่ `Code.gs`/`Index.html` ด้วยไฟล์ในโฟลเดอร์นี้
3. วาง `portal/PortalGuard.gs` เพิ่มเข้าไป แล้วแก้ `PORTAL_HUB_URL`
4. Deploy ใหม่ — ยังเป็น shadow mode จนกว่าจะยืนยัน mapping รหัสโครงการและสิทธิ์
   ผู้ใช้จริงถูกต้องแล้ว
